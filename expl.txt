│                       MAVEN                              │  provided = « Nécessaire pour compiler et exécuter, mais fournie par Tomcat → donc pas dans le WAR. »

│                                                          │  compile = « Nécessaire pour compiler et exécuter, et je dois la fournir → donc dans le WAR. »
                                                              Exemple : hibernate-core — mon code écrit import org.hibernate.Session; → il me la faut partout.

                                                              Exemple : postgresql — mon code n'écrit jamais import org.postgresql.Driver mais Hibernate la charge à l'exécution via Class.forName.
